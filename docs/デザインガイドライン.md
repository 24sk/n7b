## 1. ブランドアイデンティティ

### 1.1 ブランドコンセプト

**つくる、記す、つながる。ここが僕たちのベースキャンプ。**

茅ヶ崎・南湖の海辺に位置する、ものづくり・システム開発・発信の拠点。フィールド (自然・地域) との接点を起点に、アイデアを形にし、学び合うコミュニティを育てる場所。

### 1.2 ブランドキーワード

- **フィールド (Field)** — 自然との接続、海辺、地域性
- **ベースキャンプ (Base Camp)** — 拠点、出発点、帰る場所
- **つくる・記す・つながる** — 制作・記録・コミュニティの3軸

### 1.3 ビジュアルムード

|要素|方向性|
|---|---|
|雰囲気|自然体・落ち着き・温かみ・知的|
|避けるもの|過度にポップ・冷たいIT感・装飾過多・派手|
|参考イメージ|ランタンの灯り、手書きノート、海辺の砂、木のテーブル|

### 2.2 カラー使用ルール

**ティールの使い分け**

- `teal-700` を基準のブランドカラーとし、CTA・ロゴ・主要リンクに統一
- `teal-800` は `teal-700` のhover時のみ
- `teal-100` 以下は背景や控えめな強調にのみ使用、テキスト色にはしない

**コントラスト比 (WCAG AA 準拠)**

- 通常テキスト: 4.5:1 以上
- 大きいテキスト (18pt以上 or 14pt太字以上): 3:1 以上
- `teal-700` on `white` → 5.8:1 ✓
- `neutral-700` on `white` → 9.2:1 ✓
- `neutral-500` on `white` → 4.6:1 ✓ (本文用途は非推奨、キャプションのみ)

**禁止組み合わせ**

- ティール背景にイエローテキスト (コントラスト不足)
- 純黒 (`#000`) は使わない、`neutral-900` を使う

## 3. タイポグラフィ

### 3.1 フォントファミリー

#### 見出しフォント

**LINE Seed JP ExtraBold (weight: 800)** を見出し (`h1`〜`h6`) に使用。温かみと個性を持ちつつ日本語可読性が高い。`public/fonts/LINESeedJP_OTF_Eb.woff2` としてセルフホスティング。

```css
font-family: "LINE Seed JP", "Noto Sans JP", "Hiragino Sans", sans-serif;
font-weight: 800;
```

#### 本文フォント

**Noto Sans JP Regular (weight: 400)** を本文に使用。サブセット化必須(後述)。

```css
font-family: "Noto Sans JP", "Hiragino Sans", "Yu Gothic UI", "Meiryo", sans-serif;
```

### 3.2 フォントウェイト

|ウェイト|使用箇所|
|---|---|
|400 (Regular)|本文|
|500 (Medium)|UIラベル、ボタンテキスト|
|800 (ExtraBold)|見出し (LINE Seed JP)|

見出しは LINE Seed JP 800 の存在感を活かし、本文側はウェイトを上げすぎない。

### 3.3 タイプスケール

ヒーロー以外は控えめなサイズ設定。落ち着きを優先。

|用途|サイズ (px)|line-height|weight|トークン|
|---|---|---|---|---|
|ヒーロー H1|48 / 56 (sp/pc)|1.4|700|`text-hero`|
|ページ H1|32 / 40|1.4|700|`text-h1`|
|セクション H2|24 / 28|1.4|700|`text-h2`|
|サブセクション H3|18 / 20|1.5|700|`text-h3`|
|本文 (大)|16 / 16|1.7|400|`text-body-lg`|
|本文|14 / 15|1.7|400|`text-body`|
|キャプション|12 / 13|1.5|400|`text-caption`|
|ボタン|14 / 15|1.0|500|`text-button`|
|価格 (大)|18 / 20|1.2|700|`text-price`|

### 3.4 日本語タイポグラフィのルール

- **読点と句点の前後**: `font-feature-settings: "palt"` で詰める
- **行間**: 日本語本文は `line-height: 1.7` を基準 (英文より広め)
- **文字間**: ヒーロー大見出しのみ `letter-spacing: 0.02em` で軽く広げる
- **改行**: 意味の塊で改行 (BR タグは控えめに、CSSの `white-space` 制御を優先)
- **キャッチコピー**: 句読点を文字として扱い、デザイン要素として配置

### 3.5 フォント読み込みの最適化

```html
<!-- 日本語フォントはサブセット化必須 -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+JP:wght@400;500;700&family=Inter:wght@400;500;700&display=swap" rel="stylesheet">
```

Nuxt 4 では `@nuxtjs/google-fonts` または `unfonts` モジュールを使い、ビルド時にWoff2変換とプリロード設定を自動化する。

|要素|方向性|

|用途|比率|推奨サイズ|
|---|---|---|
|ヒーロー|16:9 (PC) / 4:3 (SP)|1920×1080 / 1200×900|

- **alt属性**: 装飾画像は `alt=""`、意味のある画像は内容を簡潔に記述

## 8. レイアウトパターン

### 8.1 ヒーローセクション

PC・モバイルともに **フルブリード (画面幅いっぱい) のビジュアル** を背景レイヤーに敷き、その上にテキストを左寄せでオーバーレイする構成。トップページのファーストビューを写真の主役感で占有し、N7Bが「フィールド」としての場所性を持つことを伝える。

レイヤー構成 (奥 → 手前):

1. 背景ビジュアル: `<NuxtImg>` で配信する大判写真 (海・拠点・ものづくりの様子など)。`object-cover` で領域全体を埋める
2. グラデーションオーバーレイ: テキスト可読性を確保するため `from-neutral-900/80` → `to-neutral-900/20` のように、テキスト側 (左下) を濃く、写真側 (右上) を薄くするグラデーションを重ねる
3. コンテンツ: 左寄せのテキストブロックと CTA、下寄せ配置
4. 補助情報ボックス (PC のみ): 白カード + `backdrop-blur` で右上にフロート配置。モバイルではセクション下部に独立した白カードとして並べる

高さの目安:

- PC: `min-h-[680px]` を下限に設定。ビューポート比率 (`vh`) ではなく固定 px にすることで、縦長ディスプレイで余白が膨らむのを防ぐ
- モバイル: `min-h-[600px]`。テキスト + CTA がスクロールなしで収まる最小サイズを担保
- 上下パディングは `lg:pt-36 lg:pb-28` を目安に。ヘッダー (`h-20`) との被りを避けつつ、コンテンツ下部に程よい余白を残す

要素:

- メインキャッチ (大見出し + 黄色アンダーライン)
- サブキャッチ (1行)
- 説明文 (3〜4行)
- プライマリCTA
- 補助情報ボックス (拠点の3つの軸)

テキスト色:

- 大見出し・サブキャッチ: `text-white`
- 説明文: `text-white/85` (本文の主張を1段抑える)
- 補助情報ボックス内: 白カード上のため通常通り `neutral-900` / `neutral-700`

### 8.2 商品セクション

要素:

- セクションタイトル + アイコン (旗マーク)
- 導入文 (2行)
- 商品カードグリッド (PC 5列 / タブレット 2列 / モバイル 1列)
- 左右ナビゲーション矢印 (PCのみ表示)
- 「すべての〇〇を見る」リンク (右上)

### 8.3 4カテゴリセクション

PC 4列 / タブレット 2列 / モバイル 1列。 カード上部に大きな写真、下部に半透明オーバーレイで英語タイトル + 日本語ラベル。

### 8.4 お問い合わせ&お知らせセクション

PC 2カラム (左: 大きいCTAブロック / 右: お知らせリスト) モバイル: 縦並び

### 8.5 フッター

- 上段: ロゴ + ナビゲーション (3〜5列) + SNSアイコン
- 下段: コピーライト
- 背景: `teal-900`
- テキスト: 白 + `white/70` のサブ階層

## 9. アニメーション・モーション

### 9.1 トランジション

|種類|duration|easing|
|---|---|---|
|カラー変化|200ms|`ease-out`|
|ホバー効果|200ms|`ease-out`|
|画像ズーム|300ms|`ease-out`|
|モーダル開閉|250ms|`ease-in-out`|
|ページ遷移|300ms|`ease-in-out`|

### 9.2 ホバー効果のルール

- ボタン: 背景色を1段階濃く
- カード全体: わずかに浮かせる (`translate-y-[-2px]` + 影強化)
- 商品画像: ゆっくり拡大 (`scale-105`)
- リンクテキスト: 色変化のみ、下線は使わない (CTAは矢印アイコンが伸びる演出も可)

### 9.3 アニメーションの哲学

派手な動きは避ける。N7Bのブランドトーンは「静かなワクワク」なので、モーションも控えめに、機能を補助する範囲に留める。スクロール連動の派手な演出は不要。

## 10. アクセシビリティ

### 10.1 基本方針

WCAG 2.1 レベル AA 準拠を目標とする。

### 10.2 必須対応

- **キーボード操作**: すべてのインタラクティブ要素がTabで到達可能、`:focus-visible` で明確に表示
- **スクリーンリーダー**: 適切な`aria-label`、見出しレベルの階層構造
- **代替テキスト**: 画像には適切な`alt`属性
- **コントラスト比**: 全テキストでWCAG AA準拠
- **モーション軽減**: `prefers-reduced-motion` に対応
- **言語属性**: `<html lang="ja">` を必ず指定

### 10.3 フォーカスリング

```css
*:focus-visible {
  outline: 2px solid theme('colors.teal.600');
  outline-offset: 2px;
}
```

## 11. 文章・ボイス&トーン

### 11.1 ライティングの基本姿勢

|要素|方向性|
|---|---|
|一人称|「僕たち」 (キャッチコピー)、本文は「N7B」「南湖7丁目ベース」|
|二人称|「あなた」は避け、対象を具体的に書く|
|敬体/常体|UIテキストは敬体ベース、見出しやキャッチは体言止めも可|
|文末|「です・ます」を基本、断定が必要な場合のみ「だ・である」|
|専門用語|カタカナ語と漢字のバランスを取る、難しい用語は補足|

### 11.2 UIマイクロコピー例

## 12. ロゴ使用ルール

### 12.1 ロゴ構成

- メインマーク: 「N7B」+ 太陽アイコン
- サブテキスト: 「南湖7丁目ベース」「Field Lab & Base Camp」

### 12.2 最小サイズ

- PC: 高さ 40px 以上
- モバイル: 高さ 32px 以上
- フッター: 高さ 56px 程度

### 12.3 余白

ロゴ周囲に、ロゴ高さの 1/4 以上の余白を確保。他要素を近接させない。

### 12.4 配色バリエーション

|背景|ロゴ色|
|---|---|
|白 / 淡色|`teal-700`|
|`teal-900` (フッター)|白 + 太陽アイコンは `accent-yellow`|
|写真上|白 (ドロップシャドウで可読性確保)|

### 12.5 禁止事項

- ロゴの変形 (縦横比固定)
- ブランドカラー以外への着色
- 影やエフェクトの過剰な追加
- 背景とのコントラスト不足
