## 結論から

Google Sheets API の `appendDimension` で行を物理追加すると、**列単位の書式・条件付き書式・データ入力規則は引き継がれるのに、セル単位に設定された罫線 (borders) だけが引き継がれない**。今日 N7B がハマったのはここでした。回避策は「複製元の行から `copyPaste` で `PASTE_FORMAT` だけ貼り付ける」の一手で足ります。

この記事は、シートに行が足りなくて止まっていた RPA を「行が尽きたら自動延長する」仕様に直す過程で見つけた落とし穴の共有です。同じ轍を踏まないための備忘録として書きます。

## 何が起きたか

背景はシンプルです。とあるバックオフィス向け RPA が、毎日 Google Sheets の L 列に事前入力された URL を読んで巡回する作り方になっていました。この「事前入力」がいつしか枯れ、シートのグリッド末尾までデータが尽きてジョブが空振りしていた、というのが最初の調査結果。

対応として、ジョブ側で不足分を自動生成する仕様に変えました。Sheets API の `appendDimension` を使って行数を増やし、連番 URL を書き込むだけ。ローカルでの dry-run も通り、本番実行で 200 行が無事に追加されました。

問題はその後です。追加された行を目視確認したら、**罫線が抜け落ちて虫食い状に見える**。数値書式や背景色はきちんと入っているのに、セルを区切る細い線だけがない。

## 差分を全プロパティで取ってみる

書式まわりの不具合は「なんとなく違う」で終わらせず、API から生データを引いて比較するのが早いです。`spreadsheets.get` で `includeGridData=true` を付け、直前の既存行 (2338) と新規行 (2339) の `CellData` を全プロパティで見比べました。

差分は驚くほど狭く、以下の一点だけでした。

| 書式カテゴリ | 新規行での状態 |
|---|---|
| `numberFormat` (日付 / 通貨 など) | 引き継がれている |
| 背景色・配置・フォント | 引き継がれている |
| `dataValidation` (日付検証・チェックボックス) | 引き継がれている |
| 条件付き書式の範囲 | 自動で拡張されている |
| **`borders`** | **抜けている** |

`appendDimension` は「列に対して設定された既定書式」を新しい行にも適用する挙動なので、列全体に効く書式は引き継がれる。一方で罫線は多くの場合、セル単位に個別設定されているため、新しい行にはコピーされない。ここに認識のズレがありました。方眼紙を継ぎ足したときに、既存のマス目を延長するのではなく「白紙」がくっついてくるイメージが近いです。

## 回避策: copyPaste で書式だけ貼る

直し方は難しくありません。`batchUpdate` の `copyPaste` リクエストで、複製元 (最終行) から追加した範囲へ `pasteType: PASTE_FORMAT` を投げるだけです。

```ts
{
  copyPaste: {
    source: { sheetId, startRowIndex: 2337, endRowIndex: 2338 },
    destination: { sheetId, startRowIndex: 2338, endRowIndex: 2538 },
    pasteType: 'PASTE_FORMAT',
    pasteOrientation: 'NORMAL',
  }
}
```

`PASTE_FORMAT` は値を触らず書式だけ貼るので、既に書き込んだ L 列の URL は保持されます。実装としては `appendDimension` の直後に一度だけこのリクエストを流す形にし、`topUpTicketUrls` (URL 補充のヘルパー) に組み込みました。

すでに罫線が抜けた状態で本番に投入してしまった行への当て込みも、同じ `copyPaste` を使い捨てスクリプトで一発実行して終わりです。

## 学び: 「引き継ぐ」の定義を API のリファレンスで確かめる

つまずいた最大の理由は、`appendDimension` の「書式を引き継ぐ」という言葉を、罫線まで含めた広い意味で読み取ってしまったことです。実際は列プロパティに紐づく書式のみ。同じ「書式」でも、列単位のものとセル単位のものは API から見ると別の場所に住んでいます。

書式まわりで想定と違う挙動が出たら、まず `includeGridData=true` で生の `CellData` を引いて何が入っていて何が入っていないかを見る。これがいちばん早い診断でした。

## まとめ

- `appendDimension` は列単位の書式は引き継ぐが、セル単位の罫線は引き継がない
- 直前行から `copyPaste` の `PASTE_FORMAT` を流せば罫線だけを補える (値は無事)
- 書式のズレを疑ったら `spreadsheets.get` の `includeGridData` で生データを比較するのが最短
