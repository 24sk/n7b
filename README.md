# N7B - 南湖7丁目BASE

南湖7丁目BASEのホームページ・ECサイト。

## 技術スタック

- **フレームワーク**: Nuxt 4
- **スタイリング**: Tailwind CSS
- **決済**: Stripe
- **メール**: Resend
- **CMS**: Nuxt Content v3
- **ホスティング**: Vercel

## 開発環境のセットアップ

```bash
# パッケージインストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build
```

## 環境変数

`.env.example` を参照して `.env` を作成してください。
